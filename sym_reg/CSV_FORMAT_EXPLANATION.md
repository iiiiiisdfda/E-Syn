# MIG Circuit Analysis CSV 格式说明

## 文件格式

### 第1行：列头（Header）

```
+,!,*,&,ASTSize,ASTDepth,lev,power,area,delay
```

这是 CSV 文件的列名，定义了10个特征列：

| 列名 | 含义 | 说明 |
|------|------|------|
| `+` | OR 操作符数量 | 电路中 OR 门的数量 |
| `!` | NOT 操作符数量 | 电路中 NOT（反相器）门的数量 |
| `*` | AND 操作符数量 | 电路中 AND 门的数量 |
| `&` | 其他操作符数量 | 其他类型的逻辑门数量 |
| `ASTSize` | AST 大小 | 抽象语法树中节点的总数 |
| `ASTDepth` | AST 深度 | 抽象语法树的最大深度（层数） |
| `lev` | 逻辑层级 | 电路的最大逻辑深度（关键路径长度） |
| `power` | 功耗 | 电路的功耗估计值 |
| `area` | 面积 | 电路的面积估计值（LUT 数量或标准单元面积） |
| `delay` | 延迟 | 电路的关键路径延迟 |

### 第2行及之后：数据行

每一行代表一个 MIG 电路的特征数据。

**示例（第2行）：**
```
11.0,173.0,172.0,22.0,584,25,5,58.14,74.42,47.08
```

这表示一个电路的特征：
- `+` = 11.0（11个 OR 门）
- `!` = 173.0（173个 NOT 门）
- `*` = 172.0（172个 AND 门）
- `&` = 22.0（22个其他门）
- `ASTSize` = 584（AST 有 584 个节点）
- `ASTDepth` = 25（AST 最大深度为 25 层）
- `lev` = 5（逻辑层级为 5）
- `power` = 58.14（功耗为 58.14）
- `area` = 74.42（面积为 74.42）
- `delay` = 47.08（延迟为 47.08）

## 数据来源

这些数据是通过 `data_collect_mig.py` 脚本生成的：

1. **操作符统计**（前4列）：来自 `analyzer` 工具分析 S-expression
2. **AST 特征**（ASTSize, ASTDepth）：来自 `analyzer` 工具
3. **物理属性**（lev, power, area, delay）：来自 mockturtle 或 ABC 的 LUT mapping

## 用途

这个 CSV 文件用于：
- **XGBoost 训练**：使用前8列作为特征，预测 `area` 或 `delay`
- **符号回归训练**：使用前6列（+, !, *, &, ASTSize, ASTDepth）作为特征，预测 `delay`

## 数据统计

文件包含 100 条数据（101行 = 1行表头 + 100行数据）

每条数据代表一个随机生成的 MIG 电路的特征和物理属性。
